# Lab-SVG-Robot-Practice 🤖

## Description
A simple practice project demonstrating how to create vector graphics using SVG (Scalable Vector Graphics). This lab focuses on drawing a robot face by utilizing basic SVG tags and attributes for shapes and styling.

## Technologies & Concepts Used
* **SVG Basics:** Utilizing tags like `<svg>`, `<rect>`, and `<path>` to draw geometric shapes.
* **Grouping:** Using the `<g>` tag to group related elements (e.g., the face and eyes) and apply common attributes.
* **Styling:** Applying attributes such as `fill`, `stroke`, and `stroke-width` to color and outline the shapes.
